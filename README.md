SmartReports is a lightweight Spigot and Paper Minecraft plugin designed to streamline server moderation through interactive, clickable in-game chat alerts. When a player submits a report using the report command, online staff members receive formatted alerts with embedded buttons that let them instantly teleport to or freeze reported players directly from chat. Built with a minimal footprint to preserve server performance on high-traffic networks, the plugin features permission-gated alerts, hover tooltips, and a reloader command for live configuration updates.
